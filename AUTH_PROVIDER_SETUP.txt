
AUTHENTICATION PROVIDER SETUP
-----------------------------
Login and Sign Up now show Google, Facebook, and Microsoft provider buttons.
Google continues using the existing Google provider.
Facebook and Microsoft use Firebase Authentication popup sign-in.

IMPORTANT: Facebook and Microsoft buttons require provider setup before they
can authenticate users:
1. Firebase Console -> Authentication -> Sign-in method.
2. Enable Facebook and configure its App ID and App Secret from a Facebook
   developer app. Add the Firebase OAuth redirect URI in the Facebook app.
3. Enable Microsoft and configure its Application (client) ID and secret
   from the Microsoft Entra app registration. Use provider ID: microsoft.com.
4. Add localhost / 127.0.0.1 and the deployed website domain under Firebase
   Authentication -> Settings -> Authorized domains.

Social sign-up uses Firebase signInWithPopup. On a first successful provider
login, Firebase creates the account; on later visits it signs into that account.
The UI buttons do not bypass provider setup or pretend a login succeeded.
